# Perceived performance audit (apps/web)

Audit of every screen and every server action against `.claude/skills/michael-feedback/SKILL.md`
(rules R1 to R12) and `.claude/skills/michael-motion/SKILL.md`. Taken on main at 4339306 (14 Nov).
Owner branches: **skeletons-v2** (loading states, Suspense, layout stability), **action-feedback**
(pending, success, error for every server call), **state-transitions** (optimistic updates, in place
swaps, numbers, refreshes, navigation). Effort: S under 30 minutes, M under 1 hour, L more.

What already works and should be copied: optimistic switches with rollback and a Michael line
(`source-switches.tsx`, `agent-row.tsx`, `lib/off-the-record.ts`), recommendation cards (optimistic,
`.m-leave`, rollback with reason), chat (optimistic bubble, streamed reply, error puts the draft
back), `instructions.tsx` toggles (`useOptimistic`), `LiveRefresh` (refresh in a transition, new
items marked), skeletons with a 150ms delay and real titles.

## Top items per owner

- **skeletons-v2:** give You, Chat, connection pages, Places, Delete, Onboarding and Connect their own
  `loading.tsx` (today they show Today's skeleton); split Today and You into Suspense boundaries;
  rebuild skeletons from shared component spacing; reserve space for calendar suggestions and the
  brief.
- **action-feedback:** a `PendingButton` (client, `useFormStatus`) for the Server Component forms
  (Sync now, Disconnect, Send a test) with result lines; pending on every sheet Save; `try/finally`
  in Delete, Device key and Brief; pending on Target Accept and Set.
- **state-transitions:** optimistic Keep with `.m-leave` for calendar suggestions; goal list
  arrivals, departures and minute tweens; stable chat bubble keys; brief `.m-swap` into a reserved
  box; instant selection on the week strip; race guard on agent scopes.
